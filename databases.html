What is a database?

A database is an organized collection of data that can be stored, searched and updated.

Database types

TypeStructureExample
RelationalTables with rows and columnsOracle Database
DocumentDocuments with fieldsMongoDB
Key-valueKeys and associated valuesRedis

Why use databases?

  • Store information in an organized way.
  • Search and update records.
  • Manage access to information.
SQL is commonly used to query and manage relational databases.
